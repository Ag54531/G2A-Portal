# G2A Order Fulfillment Portal

A modern, high-conversion customer order verification and provider contact portal featuring glassmorphism design, real-time G2A 14-digit validation, dynamic WhatsApp & Telegram messaging with prefilled order IDs, multi-language support (11 languages), live CEST clock, and dark/light themes.

---

## 🚀 How to Host for FREE on GitHub Pages (in 2 minutes)

1. **Go to GitHub**: Create a new repository (e.g. `order-portal`) on [github.com/new](https://github.com/new) (keep it **Public**).
2. **Upload Files**: Click **Upload files** and drag & drop `index.html` (and optionally `README.md`) into the repository, then click **Commit changes**.
3. **Enable GitHub Pages**:
   - Go to your repository **Settings** tab (top right).
   - In the left sidebar, click **Pages** (under "Code and automation").
   - Under **Build and deployment** > **Branch**:
     - Select branch: `main`
     - Select folder: `/ (root)`
     - Click **Save**.
4. **Done!** In ~30 seconds, GitHub will give you your free live website URL:
   `https://<your-username>.github.io/<repository-name>/`

## ⚡ Features Included
- **Strict G2A Order ID Validation**: Validates 14 digits starting with `92000`.
- **Dynamic Instant Messaging**: Prefills Order ID in Telegram and WhatsApp chat links automatically.
- **Multi-Language Support**: 11 languages (English, Portuguese, Indonesian, Russian, Spanish, German, French, Polish, Turkish, Chinese, Arabic).
- **Live CEST Clock**: Real-time CEST (UTC+2) operational status and time calculation.
- **Glassmorphism UI**: Beautiful frosted glass interface with dark and light theme toggle.
- **Zero Dependencies**: 100% client-side HTML, CSS & JavaScript. No server required.
